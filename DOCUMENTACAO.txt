================================================================================
  1. VISÃO GERAL DO PROJETO
================================================================================

SmartEventManager é um sistema de gestão completo para empresas de aluguer de
equipamentos de eventos, cobrindo áudio, vídeo, iluminação, estruturas e
mobiliário.

  - Nome do projeto: SmartEventManager
  - Repositório: SmartEventPro
  - Domínio de produção: app.smartvideo.tech

TECH STACK:
  - Frontend:   Next.js 16 + React 19 + TypeScript 5
  - UI:         Shadcn/ui + Tailwind CSS 4
  - Base dados: Prisma ORM 7 + SQLite (libSQL)
  - Autenticação: JWT (jose 6) + bcryptjs (cookies HTTP-only)
  - PDFs:       jsPDF 4 + jspdf-autotable 5
  - Gráficos:   recharts 3
  - Validação:  zod 4
  - Datas:      date-fns 4
  - Toasts:     sonner 2
  - Ícones:     lucide-react
  - Font:       Lekton (Google Fonts)

================================================================================
  2. MÓDULOS IMPLEMENTADOS
================================================================================

MÓDULO 1: DASHBOARD
  - Visão geral com estatísticas (total equipamentos, disponíveis, alugados,
    em reparação, projetos ativos, orçamentos pendentes, reparações pendentes,
    faturas vencidas, colaboradores ativos, transportes pendentes)
  - Projetos recentes
  - Alertas de stock baixo (equipamentos abaixo do minStock)
  - Eventos próximos (próximos 30 dias)

MÓDULO 2: LOGÍSTICA
  - Equipamentos: Gestão de inventário com SKU, categorias, preços de aluguer,
    quantidade, stock mínimo, estado (disponível/alugado/reparação/abatido),
    atributos customizados (chave/valor), potência/peso/dimensões
  - Categorias: Hierarquia de categorias (parent/children) para equipamentos
  - Armazéns: Gestão de múltiplos armazéns
  - Movimentos de Stock: Entradas, saídas, transferências, avarias, reparações
    concluídas, com rastreabilidade por armazém, projeto e utilizador
  - Reparações: Guias de reparação com itens, custos, estado (pendente,
    em reparação, concluído, devolvido), reparador externo
  - Guias de Transporte: Gestão de transporte de equipamentos entre origem e
    destino, associadas a projetos, veículos e motoristas, com itens
    transportados e estados (pendente, em trânsito, concluído, cancelado)
  - Veículos: Frota com matrícula, marca, modelo, tipo (ligeiro/pesado/
    carrinha/camião/empilhador), combustível, capacidade (kg/m³), estado
    (disponível/em uso/manutenção/abatido), seguro e inspeção
  - Notas de Encomenda: Encomendas a fornecedores com itens, departamento,
    código de projeto, imobilizado, estados (pendente/aprovado/encomendado/
    recebido/cancelado), com PDF

MÓDULO 3: COMERCIAL
  - Orçamentos: Criação com número automático (PR_), itens (equipamento/serviço/
    mão-de-obra), cliente, datas, validade, IVA, desconto, estados
    (rascunho/enviado/aceite/recusado/expirado), PDF de orçamento
  - Clientes/Fornecedores/Entidades: Ficha única com tipo (CLIENTE/FORNECEDOR/
    ENTIDADE), dados fiscais, morada, contactos
  - Faturação: Lista de faturas com geração a partir de orçamento aceite

MÓDULO 4: RECURSOS HUMANOS
  - Colaboradores: Ficha completa com posição, departamento, taxas horária/diária,
    datas de início/fim, estado ativo
  - Departamentos: Gestão de departamentos (Áudio, Vídeo, Iluminação,
    Estruturas, Mobiliário, Administração, RH, Comercial, Transportes, Som)
  - Funções: Gestão de posições/funções (Técnico Som, Técnico Vídeo,
    Técnico Iluminação, Técnico Estruturas, Motorista, Gestor Projeto,
    Administrativo, Comercial, Diretor Técnico, Operador Logística)
  - EPIs: Equipamentos de proteção individual atribuídos a colaboradores,
    com tipo, descrição, número série, data entrega e validade
  - Certificações: Certificados e formações dos colaboradores com entidade
    emissora, datas de emissão e validade, URL do documento
  - Contratos: Tipos de contrato (sem prazo, prazo certo, parcial, prestação
    serviços, estágio) com datas e salário
  - Alocação de colaboradores a projetos (ProjectEmployee)

MÓDULO 5: FINANCEIRO
  - Faturas: Geração automática a partir de orçamento aceite com número FT_,
    estados (pendente/pago/vencido/cancelado), IVA
  - PDF de fatura (estrutura de dados implementada)

MÓDULO 6: SERVIÇOS
  - Catálogo de serviços com categoria (Vídeo, Som, Iluminação, Estruturas,
    Mobiliário, Transporte, Montagem, Outro), preço padrão, unidade
    (UN, HORA, DIA, SERVICO, KM)
  - Alocação de serviços a projetos (ProjectService)

MÓDULO 7: PROJETOS / EVENTOS
  - Projetos com número automático (PROJ_), cliente, datas, localização,
    estados (rascunho/orçamentado/confirmado/em curso/concluído/cancelado)
  - Alocação de equipamentos, serviços e colaboradores ao projeto
  - Ligação a orçamentos, faturas, movimentos de stock e guias de transporte

MÓDULO 8: DEFINIÇÕES
  - Dados da empresa (nome, morada, código postal, telefone, email, NIF, website)
    usados nos cabeçalhos/rodapés de PDFs
  - Gestão de Utilizadores (admin pode gerir users)
  - Autenticação: login/logout/registo/me com JWT

  4. PROTOCOLO DE NUMERAÇÃO
================================================================================

Todos os documentos usam um sistema de numeração automática com o formato:
  PREFIXO_SEQUENCIAL-ANO

  PR_XXXX-AAAA   →  Orçamentos (Propostas)        Ex: PR_0001-2026
  FT_XXXX-AAAA   →  Faturas                        Ex: FT_0001-2026
  PROJ_XXXX-AAAA →  Projetos                       Ex: PROJ_0001-2026
  GUI_XXXX-AAAA  →  Guias de Transporte            Ex: GUI_0001-2026
  RP_XXXX-AAAA   →  Guias de Reparação             Ex: RP_0001-2026
  NE_XXXX-AAAA   →  Notas de Encomenda             Ex: NE_0001-2026
  VC_XXXX-AAAA   →  Veículos (campo number opcional, não auto-gerado)

  XXXX = sequencial de 4 dígitos com zero-padding (0001, 0002, ...)
  AAAA = ano corrente (ex: 2026)

LÓGICA DE GERAÇÃO (exemplo para orçamentos):
  - Conta todos os registos cujo número começa com "PR_"
  - Usa count + 1 como sequencial
  - Formata: PR_0001-2026 (se for o primeiro do ano)

  8. INSTALAÇÃO EM VPS (DEBIAN/UBUNTU)
================================================================================

  Instalação do zero (um comando):
    wget https://raw.githubusercontent.com/sharillas/SmartEventPro/main/install.sh
    chmod +x install.sh
    sudo ./install.sh

  O script install.sh executa automaticamente:
    [1/9] Atualização do sistema (apt update && apt upgrade)
    [2/9] Instalação de dependências (curl, git, nginx, certbot, ufw)
    [3/9] Instalação do Node.js 22
    [4/9] Instalação do PM2 (process manager)
    [5/9] Clone do repositório para /opt/smartevent
    [6/9] Instalação de dependências npm
    [7/9] Configuração do ficheiro .env (JWT_SECRET aleatório)
    [8/9] Configuração da base de dados (prisma generate, migrate, seed)
    [9/9] Build da aplicação Next.js

  Configuração adicional automática:
    - PM2: serviço smartevent a correr em localhost:3000
    - Nginx: proxy reverso para localhost:3000, client_max_body_size 50M
    - SSL: Certbot opcional (Let's Encrypt)
    - Firewall UFW: portas 22, 80, 443 abertas

  Atualização da App na VPS:
    cd /opt/smartevent
    git pull
    npm install
    npx prisma generate
    npx prisma migrate deploy
    npm run build
    pm2 restart smartevent
